Clearings 0.4.2 - a local installer-source candidate, not an automatic publication.
This update separates installed and working helper addresses, and adds Windows, macOS, and Linux build recipes.
The standalone index.html works without Python. A future native installer can bundle the helper so recipients need no Python install.
The source ZIP is not itself a native installer; built binaries require platform checks, licensing review, and owner publication.
The app and designated release files use MPL 2.0; see LICENSE and LICENSE_SCOPE.md.
Only allowlisted code, docs, tests, fictional examples and blank GitHub planning templates are included.
Personal exports, browser data, private repository history and the working folder are not collected.
Native browser persistence at the final address still needs an owner smoke check.
Review this package before sharing. No originality certification is claimed.
