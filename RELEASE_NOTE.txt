Assistants can create and edit signed shared work before browser Refresh.

The app contains no model, account, telemetry or external runtime download.
Native binaries bundle Python; this source ZIP is also usable as a standalone browser app.
Older exports remain readable; attribution-enriched exports need 0.4.3 or newer.
Signing and platform verification limits are documented in CLEARINGS_VERIFICATION.md.
